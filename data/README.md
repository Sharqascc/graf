# Data directory

Inputs and derived artifacts for the `graf` pipeline. Only small demo
files and the synthetic fixture are committed; the full VNTraffic
dataset used for the paper is not redistributable and is not tracked.

## Layout

    data/
      raw/            source videos, homography configs, metadata (gitignored)
      interim/        per-stage outputs (gitignored)
        frames/       extracted frames
        detections/   per-frame detections
        tracks/       tracked objects (JSONL)
        trajectories/ smoothed trajectories
        homography/   per-video homography
      processed/      graph cache (gitignored)
        graphs/       per-frame PyG Data .pt files (model input)
        windows/      windowed graphs
        labels/       window labels
        ssm_events/   TTC / DRAC events
      fixtures/       synthetic data for tests and CI (committed)
      external/       third-party baselines

## Track schema (interim/tracks/*.jsonl)

Line-delimited JSON, one record per (frame, track):

    {"frame_idx": 0, "track_id": 1, "confidence": 0.9,
     "bbox_xyxy": [x1, y1, x2, y2], "actor_class": "car",
     "frame_w": 1920, "frame_h": 1080}

`filter_tracks` drops records below `min_conf` (default 0.4) and
tracks shorter than `min_len` (default 5). World coordinates are
then derived by `add_world_coords` via the homography, producing
`x_m, y_m, vx, vy, speed_mps`.

## Homography schema

    H:
      - [h00, h01, h02]
      - [h10, h11, h12]
      - [h20, h21, h22]

Maps image pixel coordinates to world metres.

## Graph schema (processed/graphs/*.pt)

One `torch_geometric.data.Data` per frame:

| attribute | shape | meaning |
|---|---|---|
| x | [num_nodes, 19] | per-actor feature vector |
| edge_index | [2, num_edges] | COO edge list |
| edge_attr | [num_edges, 15] | per-edge feature vector |
| pos | [num_nodes, 2] | world positions |
| num_nodes | int | actor count |
| frame_id | int | source frame |
| video_id | str | source video |
| track_ids | [num_nodes] | stable actor ids |
| actor_class_index | [num_nodes] | class index |
| y | [1] or empty | frame label (labels live at window level) |

## Fixture (fixtures/)

See `data/fixtures/README.md`. Generated by
`python scripts/make_fixture.py --out data/fixtures/demo`. Runs the
full pipeline end-to-end without the real VNTraffic data.

The fixture does not reproduce the paper's numbers. It proves the
code path works.

## Reproducing the paper's results

The VNTraffic dataset is not redistributed (licensing; see
`docs/dataset_protocol.md`). To reproduce:

1. Obtain the source videos and homography.
2. `python scripts/prepare_vntraffic.py --out data/raw/...`
3. `python scripts/run_detection.py`  (YOLO / RT-DETR)
4. `python scripts/run_tracking.py`   (ByteTrack / BoT-SORT)
5. `python scripts/build_graphs.py`
6. Run `scripts/compare_baselines.py` with the flags recorded in
   `docs/preregistration_sustained_r5.md`.

Exact input hashes are recorded in the paper's supplementary material.
